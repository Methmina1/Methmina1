## 🚀 Featured projects

### 📈 [StockPilot — AI-Powered Stock Analysis & Prediction](https://github.com/Methmina1/Stock-Pilot)

**Final Higher Diploma Project · AI/ML · FinTech · Full-stack**

A financial analytics application that brings together market visualizations, machine-learning predictions, and decision-support tools in an interactive interface.

- **Analyze:** stock trends, technical indicators, and financial data
- **Predict:** machine-learning forecasts and BUY / HOLD / SELL decision support
- **Explain:** model predictions using SHAP and LIME
- **Evaluate:** backtesting and prediction performance, with WebSocket-based updates

`Python` `FastAPI` `React` `PostgreSQL` `Pandas` `NumPy` `WebSockets` `Docker`

**🔗 [Explore the StockPilot repository](https://github.com/Methmina1/Stock-Pilot)**

### 🤖 Nova AI — AI-Assisted HR & Project Management

An exploration of how LLMs and intelligent workflows can support HR processes and project management in a full-stack web application.

- AI-agent and workflow orchestration concepts with **LangChain** and **LangGraph**
- LLM integration through the **DeepSeek API**
- Application development using the **MERN stack**

`MongoDB` `Express.js` `React` `Node.js` `LangChain` `LangGraph`
